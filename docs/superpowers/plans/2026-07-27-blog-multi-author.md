# Blog Multi-Author Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolve the existing single-author blog feature into multi-author support: a Payload `hasMany` relationship on `BlogPosts`, a shared `authors?: Author[]` type, and a `BlogAuthors` Astro component that renders a responsive vertical stack of author cards on the public blog post page.

**Architecture:** Payload CMS 3.80 auto-renders `hasMany` relationship fields as a multi-select with drag-and-drop ordering — no custom admin UI. The web app already fetches blog posts at `depth=2`, so a populated `authors` array (with each author's `photo` Media) comes through for free. A new `BlogAuthors.astro` component iterates the array and renders one `.blog-author-card` per author inside a `.blog-author-list` wrapper; the inner card markup and styles are preserved 1:1 from the existing `BlogAuthor.astro`, so a single author renders identically to today.

**Tech Stack:** Payload CMS 3.80 (Next.js 16, Postgres), Astro 5.x, TypeScript strict, Phosphor Icons (CDN), plain CSS per CONVENTIONS.md. No test framework exists in this repo — verification is via Payload type generation (`generate:types`), Astro build (`astro build`), and manual dev-server checks (mirroring the parent feature plan `2026-07-13-blog-author.md`).

## Global Constraints

- **CMS framework:** Payload CMS 3.80 on Next.js 16; collections are config files in `apps/cms/src/collections/`. Postgres via `@payloadcms/db-postgres` (no Prisma).
- **Web framework:** Astro 5.x; pages live in `apps/web/src/pages/`, components in `apps/web/src/components/`.
- **Styling:** 1 component = 1 `.astro` + 1 `.css` in `apps/web/src/styles/`. Repeat `:root` vars (`--yellow-color: #FAD02C; --dark-blue-color: #19304B;`) at the top of each CSS file. Use `clamp()`/`min()` for responsive sizing. **No `border-radius`** on cards. Include `:focus-visible` and `@media (prefers-reduced-motion: reduce)`. No Tailwind, no scoped `<style>`.
- **Icons:** Phosphor via CDN class `ph ph-{name}`.
- **Language:** Spanish labels/content; English class/variable names.
- **Shared types:** `packages/shared/src/index.ts` is the single source the web app imports via `@fusion-legal/shared`.
- **No test runner in the repo.** Do not introduce one. Verify via type-gen + build + dev server (matches parent feature precedent).

- [ ] **Step 3: Rewrite `BlogAuthors.astro` to iterate the array**

Replace the **entire contents** of `apps/web/src/components/BlogAuthors.astro` with:

```astro
---
import '../styles/blogauthor.css';
import type { Author } from '@fusion-legal/shared';

interface Props {
  authors?: Author[] | null;
}

const { authors } = Astro.props;
const list = (authors ?? []).filter((a): a is Author => Boolean(a && a.id));
---

{list.length > 0 && (
  <section class="blog-author-list" aria-label="Autores del artículo">
    {list.map((author) => (
      <article class="blog-author-card">
        {author.photo && (
          <div class="blog-author-photo">
            <img src={author.photo.url} alt={author.photo.alt || author.name} loading="lazy" />
          </div>
        )}
        <div class="blog-author-info">
          <h2 class="blog-author-name">{author.name}</h2>
          <p class="blog-author-cargo">{author.cargo}</p>
          <p class="blog-author-phrase">{author.phrase}</p>
          <div class="blog-author-contact">
            <a href={`mailto:${author.email}`} class="blog-author-contact-link">
              <i class="ph ph-envelope"></i>
              <span>{author.email}</span>
            </a>
            <a href={`tel:${author.phone}`} class="blog-author-contact-link">
              <i class="ph ph-phone"></i>
              <span>{author.phone}</span>
            </a>
          </div>
        </div>
      </article>
    ))}
  </section>
)}
```

Key contracts:
- `Props.authors` is `Author[] | null | undefined` — the page can pass `post.authors` directly even when it is `undefined`.
- `list` is typed as `Author[]` after the type guard; deleted-author entries (`null` in the Payload-returned array) are filtered out by `Boolean(a && a.id)`.
- When `list.length === 0`, the entire `<section>` is omitted — no layout shift beyond the missing block.
- Inner card markup (`.blog-author-photo`, `.blog-author-info`, `.blog-author-name`, `.blog-author-cargo`, `.blog-author-phrase`, `.blog-author-contact`, `.blog-author-contact-link`) is **identical** to the previous `BlogAuthor.astro`. Only the outer wrapper class changes (`.blog-author-container` → `.blog-author-card`) and is wrapped by a new `.blog-author-list`.
